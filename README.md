# GitHub Insights Pro

Dashboard analítico que consome a API pública do GitHub, construído para demonstrar
performance de nível produção: virtualização própria, web workers, charts D3
customizados, SSR e cache inteligente.

> Projeto 1 de uma série de 5 projetos de portfólio. Veja `CLAUDE.md` para o contexto
> técnico completo e o tracking de tarefas no Jira (projeto `SCRUM`).

## Stack

Nuxt 4 · TypeScript (strict) · Pinia · Tailwind CSS v4 · D3.js · Vitest

## Setup

```bash
npm install
npm run dev
```

## Métricas de performance

_A preencher ao final do Milestone 6 (SCRUM-18/SCRUM-20): Lighthouse score, Core Web
Vitals, bundle size._
